# Improve

Java 技术栈学习与实践代码集合，涵盖 Spring 源码、NIO、RabbitMQ、Sentinel、JDK 新特性等方向的练习项目。

## 内容目录

| 模块 | 说明 |
|------|------|
| `spring/` | Spring AOP 等核心机制学习 |
| `io/` | Java NIO / IO 模型实践 |
| `rabbitmq/` | RabbitMQ 消息队列使用示例 |
| `rabbit_consumer/` | RabbitMQ 消费者端实现 |
| `sentinel/` | Alibaba Sentinel 流量控制实践 |
| `new_jdk/` | JDK 新特性（虚拟线程、Record 等）探索 |
| `neiko/` | Neiko 框架学习 |

## 技术栈

- Java 17+
- Spring Framework
- RabbitMQ
- Sentinel
- Maven
